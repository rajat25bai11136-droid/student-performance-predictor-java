# Student Performance Predictor (Java CLI)

A headless, non-interactive Java command-line application designed to process student behavioral metrics and calculate predicted academic output scores. Built for automated terminal-based evaluation environments without external build system dependencies.

## Features
- Pure Java implementation (requires no external libraries or package managers).
- Supports headless execution with or without CLI arguments.
- Exports execution outputs directly to `evaluation_output.csv`.
- Clean terminal exit code status `0`.

---

## Environment & Prerequisites
- **Language:** Java JDK 8 or higher (`javac`, `java`)
